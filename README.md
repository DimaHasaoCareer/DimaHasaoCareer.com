# Dima Hasao Career

A responsive static career portal built with plain HTML, CSS and JavaScript.

## Files
- index.html — website structure/content
- style.css — responsive design
- script.js — job data, search and mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish
Upload all three files to any static hosting service or web hosting account. Keep the files in the same folder.

## Before publishing
Replace the sample job entries in `script.js` with verified vacancy information and add the correct official notification/application links. Replace the placeholder email in `index.html`.

This template is independently designed and does not copy proprietary code or branding from another website.
